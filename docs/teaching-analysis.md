### 5. ความพร้อมใช้ การดักฟัง และตัวตน

- แหล่งอ้างอิง: PDF หน้า 40–50

- คำถามกระบวนการ: เนื้อหากับ metadata เป็นข้อมูลชุดเดียวกันหรือไม่
- สิ่งที่เปลี่ยนได้: TLS และตรวจ identity, ข้อความไม่เข้ารหัส
- กลไก: tls; มี event log, ข้อมูลส่งต่อ, สถานะก่อน/หลัง และผลการรัน

- หัวข้อที่อ่านประกอบ:
  - DoS vs DDoS (PDF หน้า 42); ภาพสาธิต: คำขอเกิน capacity แล้วบริการรับอะไรได้บ้าง
  - MITM and sniffing (PDF หน้า 45); ภาพสาธิต: ผู้สังเกต traffic เห็นอะไรเมื่อใช้ TLS
