# DSI 102 ไว้ให้น้อง ๆ

สื่อการเรียน DSI 102 ที่ทำไว้ให้น้อง ๆ อ่านทบทวนและทำความเข้าใจผ่านภาพจำลอง เห็นกระบวนการทีละขั้น และลองเปลี่ยนค่าด้วยตัวเองได้

**เข้าเรียนได้เลย: [dsi102.vercel.app](https://dsi102.vercel.app/)**

## เรียนอะไรได้บ้าง

เนื้อหาครบ Week 1–8 รวม 59 บท 136 หัวข้อ พร้อมสไลด์ต้นฉบับ 514 หน้า

- Week 1: Introduction to Digital Technology
- Week 2: Computer Platforms
- Week 3: Operating Systems
- Week 4: Virtual Machines and Cloud
- Week 5: Introduction to Computer Networks
- Week 6: Network Communication
- Week 7: Network Layers and Security
- Week 8: Cyber Attacks and Defense

เลือก Week แล้วเลื่อนอ่านต่อเนื่องได้ทั้งสัปดาห์ มีตัวบอกตำแหน่งและความคืบหน้าขนาดเล็ก พร้อมเนื้อหาเต็มและปุ่มเปิด PDF เพื่อเทียบกับบทเรียนต้นฉบับ

## เรียนผ่านภาพและการทดลอง

แต่ละหัวข้อมีภาพจำลองที่ปรับค่า ดูผล และติดตามสถานะก่อน–หลังได้ เช่น การต่อสาย RJ45 การส่งแพ็กเก็ต คิว CPU หน่วยความจำ การแบ่ง subnet และการตอบสนองต่อเหตุการณ์ด้านความปลอดภัย พร้อมคำอธิบายและบันทึกเหตุการณ์ทีละขั้น

มีแฟลชการ์ดและแบบฝึกหัดสำหรับทบทวนเพิ่มเติม ใช้ธีม Arc UI รองรับมือถือ และเคารพการตั้งค่าลดการเคลื่อนไหว ความคืบหน้าและข้อมูลการเรียนบันทึกในเบราว์เซอร์ของผู้เรียน

ภาพจำลองเป็นแบบจำลองเพื่อการเรียนรู้ที่ทำงานในเว็บ โดยระบุสมมติฐานของแต่ละกระบวนการไว้ เนื้อหาเรียบเรียงช่วยอธิบายบทเรียน และสามารถเปิดสไลด์ต้นฉบับเพื่อตรวจสอบถ้อยคำ รูป และตารางได้

## เปิดโปรเจกต์บนเครื่อง

ใช้ Node.js และ npm

```sh
npm ci
npm run dev
```

เปิด http://localhost:3102

ตรวจสอบข้อมูลบทเรียนและสร้างเว็บ:

```sh
npm run check
npm run build
```

พัฒนาด้วย React, TypeScript, Vite และ PDF.js การตรวจสอบครอบคลุมเอกสารอ้างอิง ทุกหัวข้อ และแบบจำลอง 278 กรณี

## โครงสร้างเนื้อหา

- `src/data/`: เนื้อหาแต่ละ Week คำถาม แฟลชการ์ด และข้อมูลอ้างอิง
- `src/components/studio/`: หน้าเรียน ตัวอ่าน PDF และแบบจำลองกระบวนการ
- `public/pdfs/`: สไลด์ต้นฉบับสำหรับเปิดในเว็บ
- `public/content/`: ข้อความที่สกัดจาก PDF แยกตามหน้าจริง
- [docs/teaching-analysis.md](docs/teaching-analysis.md): การเชื่อมโยงบทเรียนกับแบบจำลองและขอบเขตการสอน

Week 7 และ Week 8 ยึดตามโฟลเดอร์บทเรียน: ไฟล์ต้นฉบับภายในใช้ชื่อ Week 8 และ Week 9 ตามลำดับ ตัวเว็บแสดงข้อมูลนี้เพื่อช่วยตรวจสอบแหล่งอ้างอิง เลขหน้าอ้างอิงใช้หน้าจริงของ PDF

หากอัปเดตสไลด์ ใช้ `python3 scripts/import_sources.py` (ต้องมี `pypdf`) แล้วปรับเนื้อหาและเลขหน้าอ้างอิงให้ตรงกับเอกสาร ก่อนรัน `npm run check` สามารถสร้างรายงานการเชื่อมโยงใหม่ด้วย `node scripts/analyze-teaching.cjs`

## ภาษาและการเข้าเรียน

สลับ **ไทย / English** ได้จากแถบด้านบน รวมถึงในป๊อปอัปก่อนเข้าเรียน ภาษาที่เลือกจะถูกจำไว้ในเบราว์เซอร์ และไม่ล้างสัปดาห์ที่อ่าน คำตอบ หรือค่าที่ทดลองอยู่ คำแปลทำงานจากไฟล์ในโปรเจกต์ ไม่ส่งข้อความที่ผู้เรียนกรอกไปแปลกับบริการภายนอก

PDF แสดงภาพต้นฉบับตามเดิม และมีข้อความในภาษาที่เลือกอยู่ด้านล่างสำหรับอ่านควบคู่กัน หน้าที่เป็นภาพล้วนยังต้องดูรูปจาก PDF

ก่อนเริ่มอ่าน เว็บจะแสดงป๊อปอัป **“ของฟรี ไม่มีในโลก”** ให้เปิด [Instagram มดหิ้ว](https://www.instagram.com/modhiw.offical?rpxt=ZTU5dzFvbXN1MTY4) แล้วกลับมายืนยันว่าติดตามแล้ว จึงเข้าเรียนได้ การยืนยันนี้เป็นการยืนยันด้วยตนเอง เว็บไม่ได้ตรวจการติดตามผ่าน Instagram API หรือขอรหัสผ่าน ยืนยันแล้วจะเข้าอ่านต่อได้ตลอดเซสชันของแท็บนี้

คำแปลอยู่ใน `src/i18n/` โดยใช้ข้อความสองภาษาที่มีอยู่เดิมก่อน และมีไฟล์ `overrides.json` สำหรับปรับถ้อยคำ การเพิ่มเนื้อหาควรเรียก `node scripts/collect-locales.cjs` และ `node scripts/locale-pairs.cjs` แล้วเติมคำแปลและตรวจด้วย `npm run check` สคริปต์ `translate-locales.py` เป็นตัวช่วยเตรียมคำแปลจากข้อความหลักสูตรสาธารณะผ่านบริการแปล ต้องตรวจศัพท์เทคนิคก่อนเผยแพร่
