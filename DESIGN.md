# DSI 102 reading library

Read mode. Keep the Arc interaction system and Thai/English controls, and expand its neutral surfaces into a warm paper library following the user's Notion Library Dashboard reference.

Cream paper background, white reading sheet, quiet taupe separators. Forest green navigation; restrained per-week sage, ochre, blue, lavender and terracotta cover colors. Semantic callouts: sage for the simple takeaway, blue for explanations, amber for examples, rose for misconceptions. Each has an icon and explicit label as well as color. All colors have matching dark appearances.

Course index is a library gallery with source slide previews and topic categories. Week reader follows physical PDF page order exactly, with English original titles, localized explanatory text, original diagrams, optional experiments, a compact position indicator and an optional table of contents. Main body is 16–17px, 1.85 line height, roughly 65–75 characters per line. Full details are visible in continuous reading; controls never require repeatedly changing slides.

No change to the follow gate or existing exercises. Native interactions, keyboard focus, readable contrast, mobile reflow, and reduced motion remain required.
